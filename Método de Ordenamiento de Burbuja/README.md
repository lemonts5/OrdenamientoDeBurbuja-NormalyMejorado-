Práctica: Método de Ordenamiento de Burbuja (Normal y Mejorado) en Java
Este proyecto implementa y compara dos variantes del algoritmo de ordenamiento de burbuja en el lenguaje de programación Java, desarrollado bajo una metodología de aprendizaje guiado.
Descripción del Proyecto
El programa contiene la implementación de:
1. Burbuja Normal (ordenamientoBurbuja): Recorre el arreglo completamente en cada iteración según el tamaño $n$[cite: 13].
2. Burbuja Mejorado (ordenamientoBurbujaMejorado): Optimizado mediante una variable de control (bandera/flag) que detecta si no hubo intercambios en una pasada, interrumpiendo el ciclo anticipadamente para ahorrar tiempo de ejecución[cite: 13].
3. Casos de Prueba (main): Incluye pruebas tanto para un arreglo completamente desordenado como para uno parcialmente ordenado, imprimiendo en consola el estado inicial, el desarrollo de las pasadas y el resultado final[cite: 13, 15].
Estructura del Código
El código fuente principal se encuentra en el archivo Burbuja.java, estructurado con métodos estáticos para facilitar su ejecución directa.
Requisitos de Ejecución
Tener instalado Java JDK
Un entorno de desarrollo como Visual Studio Code o cualquier otro IDE compatible con Java.
